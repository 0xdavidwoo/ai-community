# Basic Next.js Project

This repository contains a minimal Next.js project scaffold.

## Included files

- `package.json`
- `pages/index.tsx`
- `README.md`

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000).
